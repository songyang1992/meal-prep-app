# 周末备餐 · 一周健身餐

输入性别、体重和目标（减脂/增肌），自动算出每天和每餐的碳水 / 蛋白质 / 脂肪 / 膳食纤维与热量，生成：

- 🛒 **一周采购清单**：肉蛋水产 / 主食杂粮 / 蔬菜 / 水果 / 调味干货五大类，数量随参数联动，参考单价可编辑，总价实时重算
- ⏱️ **周末 3 小时备餐流程**：周六晚预处理（卤牛腱泡冷水过夜）→ 周日卤锅 / 煎锅 / 电饭煲 / 蒸锅四线并行
- 📖 **6 张菜谱卡**：卤牛腱、卤鸡腿+卤蛋、蒜香黑椒鸡胸、白灼虾仁、杂粮饭+蒸薯玉、焯水什锦蔬菜，全部经得起冷冻复热
- 📦 **14 盒分装表**：一周 7 天 × 午/晚餐，每盒精确克数 + 拳头/掌心估量 + 热量 + 冷藏/冷冻安排

## 计算模型

```
全天目标 = 午餐 + 晚餐 + 餐外固定项（卤蛋 1 枚 + 低 GI 水果 250g，可开关）
每日营养素 = 体重(kg) × 每公斤比例（减脂默认 碳 2.0 / 蛋 1.5 / 脂 0.8，增肌 4.0 / 1.9 / 0.8，均可滑块调节）
生肉克数 = 目标蛋白质 ÷ 0.2      （生肉蛋白质≈20%）
生米面克数 = 目标碳水 ÷ 0.75     （生主食碳水≈75%）
脂肪 ≈ 100% 来自烹调油，不进购物清单，只给油脂选择建议
```

膳食纤维目标 25–30g/天（中国营养学会 DRIs）；蔬菜 500g/天。

## 本地开发

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # 产物在 dist/，纯静态，可部署到任何静态托管
```

技术栈：React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui。无后端，参数与改过的单价存于浏览器 localStorage。

## 部署分享

### GitHub Pages（推荐，推送即自动发布）

本仓库自带 `.github/workflows/deploy.yml`：

1. 推送到 GitHub 后，进入仓库 **Settings → Pages → Source**，选择 **GitHub Actions**
2. 每次 push 到 `main` 分支自动构建并发布到 `https://<用户名>.github.io/<仓库名>/`

### Vercel / Netlify

`npm run build` 后把 `dist/` 拖进去即可，或用其 CLI 关联仓库自动部署。

## 数据与免责

- 营养素数据来自健身餐笔记整理（与《中国食物成分表》口径一致），换算公式（÷0.2 / ÷0.75）为估算口径
- 单价为小象超市 / 七鲜超市北京参考价，仅用于预算估算，实际以下单页为准
- 本工具是膳食参考，不构成医疗建议
